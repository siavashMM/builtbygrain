# Product Roadmap

This roadmap keeps the first versions small and useful.

## Phase 1: Foundation

- Create monorepo structure.
- Add documentation.
- Generate Angular frontend later.
- Generate Spring Boot backend later.
- Add local development setup.

## Phase 2: Catalog

- Manage products.
- Show product listing.
- Show product detail pages.
- Store product images and descriptions.

## Phase 3: Cart and Orders

- Add shopping cart.
- Create orders.
- Add order status management.
- Add basic admin order view.

## Phase 4: Payments

- Integrate Stripe.
- Handle payment success and failure.
- Store payment references.

## Phase 5: Shipping

- Add DHL tracking data.
- Show tracking status to customers.
- Add admin shipping workflow.
